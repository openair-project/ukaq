# Package index

## Access Metadata

Functions to access UK air quality site metadata, including geographic
and technical information.

- [`import_ukaq_meta()`](https://openair-project.github.io/ukaq/reference/import_ukaq_meta.md)
  [`import_ukaq_pollutants()`](https://openair-project.github.io/ukaq/reference/import_ukaq_meta.md)
  : Import UK Air Quality Metadata

## Import Air Quality Data

Functions to import air quality data for specific monitoring sites in a
variety of different formats and aggregations.

- [`import_ukaq_measurements()`](https://openair-project.github.io/ukaq/reference/import_ukaq_measurements.md)
  : Import Continuous UK Air Quality Monitoring Data
- [`import_ukaq_summaries()`](https://openair-project.github.io/ukaq/reference/import_ukaq_summaries.md)
  : Import Monthly and Annual Summaries of UK Air Quality Data
- [`import_ukaq_daqi()`](https://openair-project.github.io/ukaq/reference/import_ukaq_daqi.md)
  : Import UK Daily Air Quality Index Data
